## Cấu trúc thư mục mã nguồn bài tập

- **Bài 2 (Trang 15-16)**: Khai phá dữ liệu thu nhập Adult Income (`adult.data.csv`, `adult.test.csv`)
  - Câu 1 -> Câu 10: Tiền xử lý, tương quan Pearson, mã hóa One-hot vector, cây quyết định ID3, CART, Gaussian Naïve Bayes, và so sánh hiệu năng.
- **Bài 4 (Trang 26)**: Phân lớp chất lượng rượu vang đỏ Red Wine Quality (`winequality-red.csv`)
  - Câu 3 -> Câu 10: Tương quan Pearson, phân chia train/test 70-30, xây dựng mô hình ID3, CART, Naïve Bayes, và so sánh.
- **Bài 5 (Trang 26, 27)**: Chẩn đoán nguy cơ bệnh tim Heart Disease (`heart.csv`)
  - Câu a, Câu 3 -> Câu 10: Đổi tên 14 thuộc tính y sinh, khảo sát Pearson, mã hóa One-hot, huấn luyện cây ID3, CART, Naïve Bayes, và so sánh.
- **Bài 6 (Trang 27)**: Phân loại nấm độc Mushroom (`mushrooms.csv`)
  - Câu 4 -> Câu 10: Mã hóa categorical toàn diện sang One-hot, phân loại nhãn `class` (poisonous / edible), đánh giá độ chính xác tuyệt đối (100%) của cây quyết định.
- **Bài 7 (Trang 27 - 31)**: Xây dựng ứng dụng nhận dạng chữ số viết tay MNIST (`digits`)
  - Tiền xử lý ảnh xám, phân ngưỡng nhị phân với PIL, huấn luyện cây ID3 và nhận dạng ảnh chụp chữ số viết tay bên ngoài.
- **Bài 2 (Trang 32)**: Bài tập thêm tính giá trị F-measure
  - Tính F-measure lý thuyết cho Bài 1, Bài 2 và tổng hợp bảng so sánh thực nghiệm trên các bộ dữ liệu cơ bản.
